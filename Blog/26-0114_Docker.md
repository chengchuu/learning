## 镜像

| 类别 | 命令 | 说明 |
|------|------|------|
| 查看 | `docker image ls` | 镜像列表 |
| 拉取 | `docker pull IMAGE_NAME:TAG` | 指定标签 |
| 删除 | `docker rmi IMAGE_NAME:TAG` | 删除指定标签 |
| - | `docker rmi IMAGE_ID` | 通过 ID 删除 |
| - | `docker image prune -a` | 删除所有未使用的镜像 |
| 保存 | `docker save IMAGE_NAME:TAG \| gzip > FILE_NAME.tar.gz` | 保存和压缩 |
| 加载 | `docker load -i IMAGE_FILE.tar.gz` | 从压缩文件加载 |
| 标签 | `docker tag SOURCE_IMAGE:TAG TARGET_IMAGE:TAG` | 添加标签 |
| 构建 | `docker build -t IMAGE_NAME:TAG . ` | - |
| - | `docker build --no-cache -t IMAGE_NAME:TAG . ` | 不使用缓存 |

## 容器

| 类别 | 命令 | 说明 |
|------|------|------|
| 运行 | `docker run -d --name CONTAINER_NAME IMAGE_NAME:TAG` | 后台运行 |
| - | `docker run -p HOST_PORT:CONTAINER_PORT IMAGE_NAME:TAG` | 端口映射 |
| - | `docker run -v HOST_PATH:CONTAINER_PATH IMAGE_NAME:TAG` | 挂载数据卷 |
| - | `docker run --restart=unless-stopped IMAGE_NAME:TAG` | 设置自动重启 |
| 管理 | `docker ps` | 查看运行中的容器 |
| - | `docker ps -a` | 查看所有容器 |
| - | `docker start CONTAINER_NAME` | 启动 |
| - | `docker stop CONTAINER_NAME` | 停止 |
| - | `docker rm CONTAINER_NAME` | 删除 |
| 操作 | `docker exec -it CONTAINER_NAME bash` | 进入容器交互式 |
| - | `docker exec CONTAINER_NAME COMMAND` | 在容器中执行命令 |
| - | `docker logs CONTAINER_NAME` | 查看日志 |
| - | `docker logs CONTAINER_NAME -f` | 实时查看日志 |
| - | `docker logs CONTAINER_NAME --tail=N` | 查看最后 N 行日志 |
| 信息 | `docker inspect CONTAINER_NAME` | 查看详细信息 |
| - | `docker stats CONTAINER_NAME` | 查看资源使用 |
| 文件操作 | `docker cp CONTAINER_NAME:/CONTAINER/PATH /HOST/PATH` | 从容器复制文件到宿主机 |
| - | `docker cp /HOST/PATH CONTAINER_NAME:/CONTAINER/PATH` | 从宿主机复制文件到容器 |
| 更新 | `docker update --restart=always CONTAINER_NAME` | 更新重启策略 |
| - | `docker rename OLD_NAME NEW_NAME` | 重命名 |

## 网络

## 🎯 Docker Compose 命令

| 类别 | 命令 | 说明 | 使用场景 |
|------|------|------|----------|
| **启动服务** | `docker compose up -d` | 创建并后台启动服务 | 首次部署、配置更新 |
| | `docker compose -f FILE_PATH up -d` | 指定配置文件启动 | 使用非默认配置文件 |
| | `docker compose -p PROJECT_NAME up -d` | 指定项目名启动 | 自定义项目名称 |
| | `docker compose start` | 启动已存在的容器 | 快速重启已停止的服务 |
| **停止服务** | `docker compose down` | 停止并删除容器、网络 | 完全清理环境 |
| | `docker compose stop` | 停止容器（不删除） | 临时停止服务 |
| **重启服务** | `docker compose restart` | 重启所有容器 | 服务异常、配置重载 |
| | `docker compose restart SERVICE_NAME` | 重启指定服务 | 单个服务重启 |
| **查看状态** | `docker compose ps` | 查看服务状态 | 检查容器运行情况 |
| | `docker compose ps -a` | 查看所有容器（包括停止的） | 全面检查 |
| | `docker compose config` | 验证并查看配置 | 配置文件检查 |
| | `docker compose config --quiet` | 静默验证配置 | 脚本中使用 |
| **日志管理** | `docker compose logs` | 查看所有服务日志 | 问题排查 |
| | `docker compose logs -f` | 实时查看日志 | 动态监控 |
| | `docker compose logs --tail=50` | 查看最后 N 行日志 | 快速查看最近日志 |
| | `docker compose logs SERVICE_NAME` | 查看指定服务日志 | 单服务排查 |
| **容器操作** | `docker compose exec SERVICE_NAME bash` | 进入容器 | 容器内部操作 |
| | `docker compose exec SERVICE_NAME COMMAND` | 在容器中执行命令 | 运维操作 |
| | `docker compose exec -T SERVICE_NAME COMMAND` | 非交互式执行命令 | 脚本/备份操作 |
| **镜像管理** | `docker compose pull` | 拉取最新镜像 | 镜像更新 |
| | `docker compose build` | 构建镜像 | 使用 Dockerfile 构建 |
| | `docker compose build --no-cache` | 不使用缓存构建 | 强制重新构建 |
| **其他操作** | `docker compose pause` | 暂停服务 | 临时暂停 |
| | `docker compose unpause` | 恢复服务 | 恢复暂停的服务 |
| | `docker compose top` | 查看容器进程 | 性能监控 |

## 🔧 Docker 系统命令

| 类别 | 命令 | 说明 | 使用场景 |
|------|------|------|----------|
| **系统信息** | `docker version` | 查看 Docker 版本 | 版本检查 |

| | `docker system prune` | 清理未使用资源 | 系统清理 |

| | `systemctl start docker` | 启动 Docker 服务 | 服务启动 |
| | `systemctl stop docker` | 停止 Docker 服务 | 服务停止 |
| | `systemctl restart docker` | 重启 Docker 服务 | 服务重启 |
| | `systemctl enable docker` | 设置开机自启 | 自动启动 |

## 🔍 常用组合命令

| 场景 | 命令 | 说明 |
|------|------|------|
| **批量停止容器** | `docker stop $(docker ps -q)` | 停止所有运行中的容器 |
| **批量删除容器** | `docker rm $(docker ps -aq)` | 删除所有容器 |
| **批量删除镜像** | `docker rmi $(docker images -q)` | 删除所有镜像 |
| **删除所有停止的容器** | `docker container prune` | 清理停止的容器 |
| **查看容器 IP** | `docker inspect -f '{{range. NetworkSettings.Networks}}{{.IPAddress}}{{end}}' CONTAINER_NAME` | 获取容器 IP 地址 |
| **查看端口映射** | `docker port CONTAINER_NAME` | 查看容器端口映射 |
| **实时监控日志** | `docker logs -f --tail 100 CONTAINER_NAME` | 实时查看最后 100 行日志 |

## 💡 实用技巧

| 技巧 | 命令示例 | 说明 |
|------|----------|------|
| **指定配置文件路径** | `docker compose -f /PATH/TO/docker-compose.yml up -d` | 使用非当前目录的配置文件 |
| **指定环境变量文件** | `docker compose --env-file .env. prod up -d` | 使用特定环境变量文件 |
| **合并多个配置文件** | `docker compose -f base.yml -f override.yml up -d` | 配置文件合并 |

| **强制重建并启动** | `docker compose up -d --build --force-recreate` | 强制重建容器 |
| **查看最终配置** | `docker compose config` | 查看合并后的最终配置 |

## ⚠️ 危险命令警告

| 命令 | 危险性 | 说明 |
|------|--------|------|
| `docker system prune -a --volumes` | ⚠️⚠️⚠️ 极高 | 删除所有未使用的镜像、容器、网络、数据卷 |
| `docker image prune -a` | ⚠️⚠️ 高 | 删除所有未使用的镜像 |
| `docker volume prune` | ⚠️⚠️ 高 | 删除所有未使用的数据卷（数据丢失） |
| `docker rm -f $(docker ps -aq)` | ⚠️⚠️⚠️ 极高 | 强制删除所有容器 |
| `docker compose down -v` | ⚠️⚠️ 高 | 停止服务并删除数据卷（数据丢失） |
