## 镜像

以下命令默认在项目根目录 (包含 `Dockerfile` 的目录) 下运行。

| 类别 | 命令 | 说明 |
|:---|:---|:---|
| 构建 | `docker build -t IMAGE_NAME:TAG .` | 构建镜像 |
| ＿＿ | `docker build --no-cache -t IMAGE_NAME:TAG .` | 不使用缓存 |
| 查看 | `docker image ls` | 镜像列表 |
| 拉取 | `docker pull IMAGE_NAME:TAG` | 指定标签 |
| 删除 | `docker rmi IMAGE_NAME:TAG` | 删除指定标签 |
| ＿＿ | `docker rmi IMAGE_ID` | 通过 ID 删除 |
| ＿＿ | `docker image prune` | 删除悬空镜像 (安全) |
| ＿＿ | `docker image prune -a` | 删除所有未使用的镜像 |
| 保存 | `docker save IMAGE_NAME:TAG \| gzip > FILE_NAME.tar.gz` | 保存和压缩 |
| 加载 | `docker load -i IMAGE_FILE.tar.gz` | 从压缩文件加载 |
| 标签 | `docker tag SOURCE_IMAGE:TAG TARGET_IMAGE:TAG` | 添加标签 |
| 推送 | `docker push IMAGE_NAME:TAG` | 推送镜像到仓库 |

## 容器

| 类别 | 命令 | 说明 |
|:---|:---|:---|
| 运行 | `docker run -d --name CONTAINER_NAME IMAGE_NAME:TAG` | 后台运行 |
| ＿＿ | `docker run --rm IMAGE_NAME:TAG` | 容器退出后自动删除 (临时容器) |
| ＿＿ | `docker run -p HOST_PORT:CONTAINER_PORT IMAGE_NAME:TAG` | 端口映射 |
| ＿＿ | `docker run -v HOST_PATH:CONTAINER_PATH IMAGE_NAME:TAG` | 挂载数据卷 |
| ＿＿ | `docker run --restart=unless-stopped IMAGE_NAME:TAG` | 设置自动重启 |
| 管理 | `docker ps` | 查看运行中的容器 |
| ＿＿ | `docker ps -a` | 查看所有容器 |
| ＿＿ | `docker start CONTAINER_NAME` | 启动 |
| ＿＿ | `docker stop CONTAINER_NAME` | 停止 |
| ＿＿ | `docker rm CONTAINER_NAME` | 删除 |
| 操作 | `docker exec -it CONTAINER_NAME bash` | 进入容器交互式 |
| ＿＿ | `docker exec CONTAINER_NAME COMMAND` | 在容器中执行命令 |
| ＿＿ | `docker logs CONTAINER_NAME` | 查看日志 |
| ＿＿ | `docker logs CONTAINER_NAME -f` | 实时查看日志 |
| ＿＿ | `docker logs CONTAINER_NAME --tail=N` | 查看最后 N 行日志 |
| 信息 | `docker inspect CONTAINER_NAME` | 查看详细信息 |
| ＿＿ | `docker stats CONTAINER_NAME` | 查看资源使用 |
| 文件 | `docker cp CONTAINER_NAME:/CONTAINER/PATH /HOST/PATH` | 从容器复制文件到宿主机 |
| ＿＿ | `docker cp /HOST/PATH CONTAINER_NAME:/CONTAINER/PATH` | 从宿主机复制文件到容器 |
| 更新 | `docker update --restart=always CONTAINER_NAME` | 更新重启策略 |
| ＿＿ | `docker rename OLD_NAME NEW_NAME` | 重命名 |

## Compose

以下命令默认在项目根目录 (包含 `docker-compose.yml` 的目录) 下运行。

| 类别 | 命令 | 说明 |
|:---|:---|:---|
| 启动 | `docker compose up -d` | 创建并后台启动 |
| ＿＿ | `docker compose -f FILE_PATH up -d` | 指定配置文件 |
| ＿＿ | `docker compose -p PROJECT_NAME up -d` | 指定项目名 |
| ＿＿ | `docker compose up -d --build` | 构建后启动 |
| ＿＿ | `docker compose up -d --no-deps SERVICE_NAME` | 仅更新/重建指定服务 (不处理依赖服务) |
| ＿＿ | `docker compose start` | 启动已存在的容器 |
| 停止 | `docker compose down` | 停止并删除容器、网络 |
| ＿＿ | `docker compose -f FILE_PATH down` | 指定配置文件 |
| ＿＿ | `docker compose stop` | 停止容器 (不删除) |
| 拉取 | `docker compose pull` | 拉取服务镜像 (不启动容器) |
| ＿＿ | `docker compose pull SERVICE_NAME` | 仅拉取指定服务镜像 |
| 重启 | `docker compose restart` | 重启所有服务 |
| ＿＿ | `docker compose restart SERVICE_NAME` | 重启指定服务 |
| 状态 | `docker compose ps` | 查看状态 |
| ＿＿ | `docker compose config` | 验证并查看配置 |
| 日志 | `docker compose logs` | 查看所有日志 |
| ＿＿ | `docker compose logs -f` | 实时查看日志 |
| ＿＿ | `docker compose logs --tail=N` | 查看最后 N 行日志 |

## Dockerfile

常用 Dockerfile 指令:

| 指令 | 示例 | 说明 |
|:---|:---|:---|
| `FROM`    | `FROM node:20-alpine` | 指定基础镜像 |
| `ENV`     | `ENV NODE_ENV=production` | 设置环境变量 (可设置多个) |
| `WORKDIR` | `WORKDIR /app` | 设置工作目录 |
| `COPY`    | `COPY ./dist /app/dist` | 复制本地文件到镜像 (推荐) |
| `ADD`     | `ADD https://a.com/b.tar.gz /PATH/` | 复制文件到镜像，支持 URL 和解压 |
| `RUN`     | `RUN npm ci --omit=dev` | 构建阶段执行命令 (安装依赖/构建等) |
| `EXPOSE`  | `EXPOSE 3000` | 声明容器监听端口 (文档性质) |
| `VOLUME`  | `VOLUME ["/var/lib/mysql"]` | 声明挂载点 |
| `CMD`     | `CMD ["node", "server.js"]` | 设置容器默认启动命令 |

备注:

- 生产实践中，文件复制优先使用 `COPY`，仅在需要 `ADD` 的额外能力 (如 URL/自动解压) 时使用 `ADD`。
- `CMD` 适合作为默认命令；若镜像需要固定主进程，通常结合 `ENTRYPOINT` 使用。
- `EXPOSE` 仅声明容器端口；实际对外发布仍需 `docker run -p` 或 Compose `ports`。

## 附录

### 删除所有容器

停止 & 删除所有容器:

```bash
#!/bin/bash
# docker-stop-remove-all-containers.sh
set -e

# Stop
echo "Stop Docker Containers ..."
RUNNING_CONTAINERS=$(docker ps -q)
if [ -n "${RUNNING_CONTAINERS}" ]; then
  docker stop ${RUNNING_CONTAINERS}
else
  echo "No running containers to stop"
fi

# Remove
echo "Remove Docker Containers ..."
ALL_CONTAINERS=$(docker ps -a -q)
if [ -n "${ALL_CONTAINERS}" ]; then
  docker rm ${ALL_CONTAINERS}
else
  echo "No containers to remove"
fi
```

### Compose 示例

`docker compose up -d --build` & `docker-compose.yml` 示例:

```yaml
name: web
services:
  web-frontend:
    build:
      context: .
      dockerfile: Dockerfile
    image: web-frontend:latest
    container_name: web-frontend
    ports:
      - "8080:80"
    volumes:
      - "/host/html:/usr/share/html"
    restart: unless-stopped
  web-backend:
    image: web-backend:latest
    container_name: web-backend
    ports:
      - "3000:3000"
    environment:
      ENV: "production"
    restart: unless-stopped
```

### Nginx Mock 镜像示例

用于本地联调时快速提供一个可访问的 HTTP mock 服务。仅在容器网络内使用 (不暴露宿主机端口):

```yml
name: mock
services:
  mock-hello:
    image: nginxdemos/hello:plain-text
    container_name: mock-hello
    expose:
      - "80"
    restart: unless-stopped
```

### 从容器复制 MySQL Raw 文件到宿主机

Bash:

```bash
mkdir -p /PATH_A/PATH_B
docker stop CONTAINER_NAME
docker cp CONTAINER_NAME:/var/lib/mysql/. /PATH_A/PATH_B
docker start CONTAINER_NAME
```

YAML:

```yaml
volumes:
  - "/PATH_A/PATH_B:/var/lib/mysql"
```

### 从容器导出/导入 MySQL Dump 文件

Export:

```bash
docker exec "${CONTAINER_NAME}" mysqldump \
  --single-transaction --quick --routines --events \
  -uroot -p"${DATABASE_PASSWORD}" --databases "${DATABASE_NAME}" \
  > "${BACKUP_FILE}"
```

Import:

```bash
docker exec -i "${CONTAINER_NAME}" mysql \
  -uroot -p"${DATABASE_PASSWORD}" \
  < "${BACKUP_FILE}"
```

### 旧版本 Compose 命令

```bash
# 查看版本
docker-compose version
# 拉取镜像 (不启动)
docker-compose -p PROJECT_NAME -f FILE_PATH pull
# 启动
docker-compose -p PROJECT_NAME -f FILE_PATH up -d
# 单独更新某个服务 (不重建依赖)
docker-compose -p PROJECT_NAME -f FILE_PATH up -d --no-deps SERVICE_NAME
# 查看状态
docker-compose -p PROJECT_NAME -f FILE_PATH ps
# 停止
docker-compose -p PROJECT_NAME -f FILE_PATH down
```
